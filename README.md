# 🍼 IUmeal — 세계의 이유식 마켓 & 키친

아이 이유식을 설계하고 만드는 게임형 웹 프로그램입니다.
캐릭터를 움직여 마트에서 장을 보고, 주방에서 세계 7개국(프랑스·한국·일본·영국·미국·스웨덴·독일)의 이유식을 만들고, 사진과 아이 반응을 기록·공유합니다.

## 실행 방법

빌드·서버 없이 동작하는 순수 정적 웹앱입니다.

- `index.html`을 브라우저에서 열면 바로 실행됩니다.
- 온라인 배포: GitHub Pages 등 정적 호스팅에 그대로 올리면 됩니다.
  (Settings → Pages → 브랜치 선택 → 루트)

## 플레이 흐름

1. **프로필 설정** — 아기 이름·월령·알레르기 이력 입력 (레시피 안전 필터에 사용)
2. **🛒 마트** — 화살표/WASD(모바일: 방향 패드)로 이동, 코너 앞에서 Space/A로 식자재를 장바구니에 담기
3. **🚪 문으로 나가면 주방으로 이동** — 장바구니 식자재가 냉장고(인벤토리)에 자동 정리
4. **🍳 조리대에서 레시피북 펼치기** — 현재 보유 식자재 기준으로 각국 이유식의 **조리방법·장점·단점** 표시, 재료가 갖춰진 레시피는 바로 요리 가능
5. **📸 요리 후 기록** — 요리 사진 + 아이가 먹는 사진 촬영, 반응(완식/잘 먹음/조금/거부) 선택, 경험 메모
6. **📤 공유** — 기록을 텍스트 카드로 공유(Web Share API, 미지원 시 클립보드 복사)
7. **📔 일지** — 식사 기록 열람 + 재료별 **반복 노출 트래커**(목표 8회, 근거: 새 음식 수용에 평균 8~15회 노출 필요)
8. **📚 책장** — 국가별 접근법 비교, 근거 기반 5원칙, 한국 상황 조합안 가이드

## 근거 기반 설계 포인트

- **철분 우선**: 재료·레시피에 철분 태그, 독일 1-2-3 Brei의 철분 흡수 조합 반영
- **질감 전환 창(8~10개월)**: 퓌레류 레시피에 질감 전환 경고 포함
- **알레르겐 조기 도입(LEAP·EAT)**: 땅콩·계란 레시피 포함, 프로필 알레르기 이력 기반 경고
- **반복 노출 8~15회**: 거부 시 neophobia 코칭 메시지 + 노출 카운터 게임화
- **반응적 수유**: "양은 아이가 결정" 원칙을 레시피·코칭 문구에 반영
- **안전 수칙**: 12개월 미만 꿀 금지(재료 목록에서 제외), 질식 위험 재료 경고, 무염·무설탕

## 개인정보

모든 데이터(아기 사진 포함)는 **브라우저 localStorage에만** 저장되며 어떤 서버에도 업로드되지 않습니다. 공유는 사용자가 명시적으로 버튼을 눌렀을 때 텍스트 요약만 내보냅니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 (시작 화면, 게임 화면, 모달) |
| `style.css` | 스타일 (모바일 대응, 터치 컨트롤 포함) |
| `data.js` | 식자재 DB(24종), 7개국 레시피 DB(15종), 가이드 콘텐츠 |
| `app.js` | 게임 엔진(맵·이동·상호작용) + 상점/레시피북/기록/공유 로직 |
